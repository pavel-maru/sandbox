# Sandbox — алгоритмы и мини-программы на Python и C

Это сборник небольших учебных и экспериментальных программ, которые я написал в процессе изучения программирования.
Здесь собраны решения типовых задач, полезные сниппеты и просто интересные куски кода.

## Структура
- `sandbox-python/` — всё на Python 3.10+
- `sandbox-c/` — всё на C11 (сборка через gcc)

## Содержание (на данный момент)

| Файл | Язык | Описание |
|------|------|----------|
| `extract_digits_to_int.py` | Python | Извлекает целое число из строки, удаляя все нецифровые символы |
| `reverse_sequence.py` | Python | Переворачивает кортеж/список через срез |
| `eval_sum_expression.py` | Python | Вычисляет арифметическое выражение вида 0+1+...+n-1 через eval() |
| `cyclic_repeat_string.py` | Python | Циклически повторяет строку до заданной длины (с дробным коэффициентом) |
| `invert_dict.py` | Python | Меняет местами ключи и значения в словаре |

> По мере добавления новых файлов таблица будет пополняться.

## Как запускать
- Python: `python3 имя_файла.py`
- C: `gcc -std=c11 имя_файла.c -o prog && ./prog`
